## Especificaciones Técnicas

### Formato
- **Extensiones aceptadas:** PNG, WebP
- **Calidad:** Mínimo 80% para JPEG, lossless para PNG
- **Tamaño máximo por archivo:** 2MB

### Nomenclatura
```
01-vista-general.png
02-filtros.png
03-grafica-ventas.png
04-tabla-productos.png
05-formulario-producto.png
06-vista-movil.png
07-login.png
08-panel-admin.png
```

### Herramientas Recomendadas
- **Captura de pantalla:** Snipping Tool (Windows), Cmd+Shift+4 (Mac)
- **Responsive:** Chrome DevTools → Device Mode
- **Full page:** Chrome DevTools → Capture full size screenshot

## Cómo Agregar Capturas

1. Abrir la aplicación en el navegador
2. Navegar a la sección que se desea capturar
3. Abrir Chrome DevTools (F12)
4. Si es responsive: Activar Device Mode y seleccionar dispositivo
5. Tomar captura con Snipping Tool o atajo de teclado
6. Guardar con la nomenclatura correcta en esta carpeta
7. Actualizar el estado en la tabla de arriba
