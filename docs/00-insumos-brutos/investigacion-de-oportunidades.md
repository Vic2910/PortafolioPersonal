# Investigación de Oportunidades Laborales

> **Propósito:** Documentar una muestra de 15-20 vacantes o encargos que realmente interesen al desarrollador, registrando requisitos, nivel, idioma, ubicación y evidencias solicitadas. Esta investigación alimenta la estrategia de posicionamiento del portafolio y la personalización del contenido.

### Criterios de Búsqueda

- **Rol:** Full Stack Developer, Backend Developer, Frontend Developer
- **Nivel:** Junior, Entry Level, Mid Level
- **Modalidad:** Remoto (prioridad), Híbrido

- **Sectores:** Tecnología, Fintech, E-commerce, Startups, Salud, Educación
