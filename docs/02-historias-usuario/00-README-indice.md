# Historias de Usuario — PortafolioVRAS

> **Propósito:** Este directorio contiene las historias de usuario que definen los requisitos funcionales del portafolio. Cada historia describe una necesidad específica de un tipo de visitante y se valida contra el marco normativo.

## Formato de Historia de Usuario

Cada historia sigue el formato:

```markdown
# HU-XX: [Título de la Historia]

## Datos de la Historia
- **ID:** HU-XX
- **Título:** [Título descriptivo]
- **Como:** [tipo de visitante]
- **Quiero:** [acción o necesidad]
- **Para:** [beneficio o objetivo]
- **Prioridad:** [Alta/Media/Baja]
- **Estado:** [Pendiente/En Progreso/Completada]

## Criterios de Aceptación
1. [Criterio 1]
2. [Criterio 2]
3. [Criterio 3]

## Referencias al Marco Normativo
- `[archivo-normativo]` — [requisito aplicable]

## Notas Adicionales
- [Información complementaria]
```
