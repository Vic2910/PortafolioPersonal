# AG-03: Posible Cliente Freelance

## Datos del Agente

| Campo | Valor |
|:------|:------|
| **ID** | AG-03 |
| **Nombre** | Cliente Freelance / Emprendedor / Startup Founder |
| **Objetivo** | Evaluar si el desarrollador puede resolver su problema específico |
| **Tiempo Promedio** | 3-5 minutos |
| **Prioridad** | Media |

---

## Perfil

### ¿Quién es?
- Emprendedor que necesita desarrollar un producto digital
- Gerente de proyecto buscando desarrollador para freelance
- Startup founder que necesita MVP rápido
- PyME que busca modernizar sus sistemas

### ¿Qué busca?
- Proyectos similares al suyo
- Tecnologías específicas que necesita
- Capacidad de entrega y profesionalismo
- Costos y disponibilidad

### ¿Cómo evalúa?
- Revisión del Hero Section (5 segundos)
- Exploración de proyectos relacionados (2-3 minutos)
- Búsqueda de testimonios o referencias (1 minuto)
- Revisión de opciones de contacto (1 minuto)

---

## Recorrido Esperado

```
1. Hero Section (5 seg)
   → Entiende: Qué tipo de desarrollo hace
   → Pregunta: ¿Puede resolver mi problema?
   → Decisión: ¿Explorar más?

2. Proyectos Relacionados (2-3 min)
   → Entiende: Si ha resuelto problemas similares
   → Evalúa: Calidad del trabajo, relevancia
   → Pregunta: ¿Tiene experiencia en mi sector?

3. Habilidades (1 min)
   → Entiende: Tecnologías que domina
   → Evalúa: Si usa las que necesito
   → Pregunta: ¿Puede trabajar con mi stack?

4. Testimonios/Referencias (1 min) - Si existen
   → Entiende: Experiencia de otros clientes
   → Evalúa: Confiabilidad, puntualidad
   → Pregunta: ¿Es confiable?

5. Contacto (1 min)
   → Entiende: Cómo iniciar conversación
   → Evalúa: Facilidad de contacto
   → Acción: Enviar mensaje con proyecto
```

---

## Criterios de Evaluación

### Must Have (Eliminación)
| Criterio | Descripción | Requisito |
|:---------|:------------|:----------|
| Proyectos visibles | Trabajo anterior | Al menos 3 proyectos |
| Tecnologías relevantes | Stack que necesito | Al menos 1 tecnología |
| Contacto accesible | Formulario o email | Al menos 1 canal |
| Profesionalismo | Presentación limpia | Diseño cuidado |

### Should Have (Fortalezas)
| Criterio | Descripción | Ideal |
|:---------|:------------|:------|
| Proyectos similares | Experiencia en mi sector | 1+ proyecto similar |
| Demo disponible | Ver trabajo en acción | Links a demos |
| Caso de estudio | Narrativa de proyecto | Documentación completa |
| Formulario detallado | Captura de requerimientos | Campos específicos |

### Nice to Have (Diferenciadores)
| Criterio | Descripción | Valor Agregado |
|:---------|:------------|:---------------|
| Testimonios | Opiniones de clientes | Social proof |
| Portafolio PDF | Documento descargable | Revisión offline |
| Blog técnico | Artículos relevantes | Experiencia demostrada |

## Contenido Crítico para Este Agente

### Hero Section
- Tipo de desarrollo que realiza
- Tecnologías principales
- CTA a proyectos

### Proyectos
- Descripción clara del problema resuelto
- Tecnologías utilizadas
- Resultados y métricas

### Contacto
- Formulario con campos relevantes
- Opción de describir proyecto
- Tiempo de respuesta estimado

---

## Preguntas que Este Agente se Hace

1. ¿Ha trabajado en proyectos similares al mío?
2. ¿Usa las tecnologías que necesito?
3. ¿Tiene disponibilidad para mi proyecto?
4. ¿Cuánto costaría approximate?
5. ¿Puede entregar en el plazo que necesito?
6. ¿Cómo es su proceso de trabajo?

## Tipos de Proyectos que Busca

| Tipo de Proyecto | Tecnologías Requeridas | Complejidad |
|:-----------------|:-----------------------|:------------|
| Landing Page | React/Vue, HTML/CSS | Baja |
| E-commerce | Full Stack, Base de datos | Media |
| Dashboard | React/Angular, API | Media |
| App Móvil | React Native/Flutter | Alta |
| Sistema Web | Full Stack, Auth | Alta |
| API/Servicio | Backend, Base de datos | Media |

## Errores que Provocan Rechazo

| Error | Impacto | Solución |
|:------|:--------|:---------|
| Sin proyectos visibles | Alto | Mostrar trabajo anterior |
| Sin contacto fácil | Alto | Agregar formulario |
| Tecnologías obsoletas | Medio | Actualizar stack |
| Sin demo | Medio | Crear demos online |
| Diseño anticuado | Bajo | Modernizar apariencia |
